01

MySort

Сервис выноса мусора по подписке

Перенёс проект со старых PHP-скриптов на Laravel. В нём есть роли клиента, курьера и администратора, подписка со счётчиком выносов, три тарифа и промокоды. Оплата идёт через ЮKassa с вебхуком, вход через Яндекс ID. Ещё есть карта зоны покрытия и PWA.

Очереди и планировщик закрывают просроченные заказы и подписки, уведомления уходят в Telegram и через web-push. Работа шла в шесть этапов, к каждому написана документация.

Работает на хостинге с реальными заказами и курьерами, развивается

  • PHP 8
  • Laravel
  • MySQL
  • ЮKassa
  • Яндекс ID
  • PWA
  • Telegram

02

Оплата и управление умной розеткой

Массажное кресло в другом городе включается после оплаты

Клиент платит через ЮKassa, сервис включает розетку с креслом и отсчитывает оплаченное время. По его окончании питание гарантированно отключается, для этого есть три независимых способа. У сервиса есть публичное и админское API, драйверы разных розеток работают за единым интерфейсом.

Есть и упрощённая версия на Tuya Cloud API: кнопки «Включить» и «Выключить» плюс cron.

Выложен, платежи проходят

  • Laravel 13
  • Docker
  • ЮKassa
  • Tuya Cloud API
  • 126 автотестов
